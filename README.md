## Featured Engineering & Research

- **[llm-hallucination-mitigation](https://github.com/print-ramcharan/llm-hallucination-mitigation):** Research-oriented pipeline treating reliable LLM answering as a systems problem. Implements hybrid retrieval (dense + BM25), Reciprocal Rank Fusion (RRF), cross-encoder reranking, sentence-level context compaction, and evidence sufficiency evaluation.
- **[Context-Rot-Demo-Popular-Models](https://github.com/print-ramcharan/Context-Rot-Demo-Popular-Models):** Audited RAG implementation demonstrating context degradation mitigation. Features custom document chunking, MiniLM embeddings, FAISS vector search, and sentence compaction to optimize prompt token payloads[cite: 2].
- **[Zentra Distributed Order Management System](https://github.com/print-ramcharan/Zentra):** Architected an 8-service Spring Boot microservices platform coordinating order, payment, and inventory workflows using Apache Kafka, Saga Orchestration, and Transactional Outbox pattern[cite: 1, 2].
- **[MiniOS Operating System Kernel](https://github.com/print-ramcharan/MiniOS):** Freestanding 32-bit monolithic x86 OS kernel engineered in C and NASM Assembly[cite: 1]. Implemented memory paging, interrupt handling (IDT), and physical memory management[cite: 1].
- **[escape-the-arrows](https://github.com/print-ramcharan/escape-the-arrows):** Domain-driven Android puzzle game built in Kotlin and Jetpack Compose, featuring immutable board state transitions and fully isolated game domain logic.
