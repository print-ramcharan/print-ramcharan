## Featured Projects

- **[Zentra Distributed Order Management System](https://github.com/print-ramcharan/Zentra)**  
  Architected an 8-service Spring Boot microservices platform coordinating order, payment, and inventory workflows using Apache Kafka, Saga Orchestration, and Transactional Outbox pattern.

- **[llm-hallucination-mitigation](https://github.com/print-ramcharan/llm-hallucination-mitigation)**  
  Research pipeline treating reliable LLM answering as a systems problem using hybrid retrieval (dense + BM25), Reciprocal Rank Fusion (RRF), cross-encoder reranking, and sentence-level context compaction.

- **[Music & Audio Stream Applications](https://github.com/print-ramcharan)**  
  Custom desktop and mobile audio engine built for low-latency playback, queue management, and offline metadata indexing.
